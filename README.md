# Peddusreekanth Reddy — Portfolio Website

A high-performance developer portfolio website built using HTML, CSS, Tailwind CSS, and interactive vanilla JavaScript.

## Features
- **Neobrutalist Aesthetic**: Bold borders, vibrant accents, hard drop-shadows, and interactive micro-interactions.
- **Interactive Terminal CLI**: Retro terminal emulator with live command parser (`help`, `about`, `skills`, `education`, `projects`, `askd`, `achievements`, `theme`, `rain`, `clear`).
- **Playhtml Interactive Animations**: Draggable score badges, particle score burst celebrations, and fire hydrant rain sprinkler effect.
- **Live GitHub Statistics**: Real-time stats integration fetching live repository counts, followers, and contribution matrix for `peddusreekanthreddy7`.
- **Startup Spotlight (askd.in)**: Dedicated section showcasing the AI exam evaluation startup MVP.
- **SEO & Social Graph**: Structured JSON-LD metadata, OpenGraph tags, sitemap, and robots.txt.

## Project Structure
- `index.html`: Main portfolio website.
- `Peddusreekanth_Resume.tex`: Complete LaTeX resume.
- `images/about/headshot.jpeg`: Personal headshot photo.
- `vercel.json`: Deployment configuration for Vercel static hosting.
- `sitemap.xml` & `robots.txt`: Search engine indexing.

## Deployment
Push this repository to GitHub and import it on [Vercel](https://vercel.com/) for one-click static deployment.
